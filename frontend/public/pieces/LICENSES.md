# Piece sets

SVG piece sets copied from the [lichess.org](https://github.com/lichess-org/lila) repository
(`public/piece/<set>`). Only sets whose licence allows use in this project are included;
sets marked "non-commercial" on lichess are deliberately left out.

| cburnett | Colin M.L. Burnett | GPLv2+ |
| glass | generated from cburnett by `scripts/build-glass-pieces.mjs` | GPLv2+ |
| merida | Armando Hernandez Marroquin | GPLv2+ |
| chessnut | Alexis Luengas | Apache 2.0 |
| mpchess | Maxime Chupin | GPLv3+ |
| fantasy, celtic, spatial | Maurizio Monge | MIT |
| papercut | Nikolay Anzarov | CC BY 4.0 |

Board colour themes are plain colour values; no chess.com artwork is used.
